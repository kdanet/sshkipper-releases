Privacy

What SSHKipper sends, to whom and when. In short: our server sees license checks and, if you use SSHKipper’s own cloud sign-in, your drive tokens passing through; nothing else of yours reaches us.

visibility_off

Your data stays with you

The developer gets no keys, passwords, server list or AI conversations, and the app has no analytics. Crash reports are never sent: Help → “Save crash report…” saves a file you look over and email yourself.

key

License checks

A paid license sends its key and an anonymised Mac code on activation and from time to time: a subscription daily (every 5 hours in the last three days of the paid period), a lifetime license monthly, and when you open the License window while a renewal is awaited; on activation also the Mac’s name, which you see and can change.

download

Updates

The update check, if you allow it, reads a feed on sshkipper.com once a day, and a new version downloads from GitHub Releases. Like any download, that shows your IP address and the app’s version — no system profile is sent.

cloud

Cloud drives

Signing in to Google Drive, Yandex Disk or Dropbox with SSHKipper’s own app passes the tokens to the provider through our server (which doesn’t keep them): a one-time code at sign-in, and at every renewal of the access token (about hourly for Google while the storage is in use, automations included) the refresh token, the license key and the Mac code; with your own Client ID sign-in goes direct.

dns

Everything else

Everything else goes where you point it: your servers, the address ranges of a Local network source, your storage, the AI provider you chose, and Telegram (api.telegram.org, from this Mac or from the server) if you set up a bot for automations. A web page in a tab loads through the server you open it with, or straight from this Mac when its card says so; as in Safari, macOS checks its address against a fraudulent website list kept on this Mac and, only on a possible match, asks Safe Browsing (Google, or Tencent in mainland China) with a short hash prefix of the address, not the address itself. A public link starts the Cloudflare, ngrok or Tuna program on this Mac, and visitors reach your service through that company; “Test speed” on a SOCKS tunnel downloads a test file from speed.cloudflare.com, through the tunnel and without it. Claude Code, Codex, Cursor and ACP agents are separate programs with their own network traffic and telemetry. An extension you install is a program of its own and reaches whatever it was written to reach; a module’s scripts run on your server. Outside the pages you open, the app loads no website icons and no images from AI answers.
