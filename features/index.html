All features

A native SSH manager for macOS. It fills in keys, passwords and TOTP codes at every bastion and keeps the terminal, services, databases, files, tunnels, web consoles, remote desktops and automations of all your servers in one window. The AI agent helps you dig in — and does nothing dangerous without your “yes”. Missing something? Add it with an extension: the SDK is open and free (MIT).

01keyBastions and 2FA

A server behind two bastions — in one double-click

Normally that’s ssh -J, a password and a code from your phone at every bastion (jump host). In SSHKipper, keys, passwords and TOTP secrets live in an encrypted document, and the app fills them in at every hop. An ssh your own script starts gets them too — with ⌘⏎.

  • account_tree

    Bastion through bastion

    A chain of any length opens with a double-click.
  • swap_horiz

    SOCKS5 and HTTP proxies

    When the first bastion is reachable only through a proxy.
  • verified_user

    TOTP from anything

    A base32 secret, an otpauth:// link, a Google Authenticator export or a QR code. Push and hardware-key 2FA still ask you.
  • description

    Import ~/.ssh/config

    ProxyJump turns into bastions, port forwards into tunnels.

  • Tailscale and local network

    Machines on your network appear in the tree on their own once you add a Tailscale or Local network source.
  • lan

    Route profiles

    Tailscale, an office address or another bastion — when the main way is down.
  • target

    The route as you sign in

    This Mac, the proxy, each bastion and the server light up as the login passes them — and you see where it stopped.
  • lan

    One sign-in per server — and per bastion

    Tabs, splits, files, Docker and databases of a server share one connection, and servers behind one bastion share its connection — its 2FA comes once.
  • key

    Host keys under control

    Its own known_hosts: if a host key changes, you get a warning, not a silent sign-in.
  • hub

    Route diagram

    How this Mac reaches a server: bastions, proxies, keys and codes, drawn from the document.
  • touch_app

    When you press

    By default nothing is typed by itself: “Insert code” or ⌘⏎ puts the code straight into the terminal, not via the clipboard. For a server you trust, turn on “Type by itself after checking ssh”.
  • terminal

    In any terminal

    This Mac’s terminal and SSH tabs alike: the server is found by user and address — any profile of a connection too.
  • key_vertical

    Key passphrases too

    Once, checked against the key file — then kept in the encrypted document; the key is recognised by its fingerprint.

03auto_awesomeAI agent

The agent digs into the server itself — and asks before anything dangerous

It reads logs, load and containers on its own. It never gets the document’s passwords and keys: they are masked in everything it reads, and secret files like .env open only after your “yes”. What it may do without asking is up to you: four access levels, as in Codex — per server and folder. You pick the model, too.

  • Claude API

    Pick the model and reasoning depth right in the chat.

  • OpenAI

    GPT over the API, or any OpenAI-compatible service.

  • DeepSeek

    DeepSeek models over the API.

  • Ollama · LM Studio

    A model on this Mac: nothing leaves for the cloud.

  • Claude Code

    Your subscription and your agent; web search if you like.

  • Codex

    OpenAI’s agent in the same panel, with web search too.

  • Cursor

    Cursor’s agent answers in the same panel.
  • hub

    Other agents

    Gemini CLI, Goose, Hermes, pi over the Agent Client Protocol. Servers still go through SSHKipper’s levels; their own tools on this Mac are theirs.
  • visibility

    Secrets are masked before sending

    The document’s passwords and keys, and tokens of known formats, become [REDACTED] before anything goes to a model; .env, keys and shell history need your “yes”. Claude Code and Codex get your Mac’s shell and files only at “Full access”.
  • verified_user

    A plan in one card

    Several steps, each with a verdict and a rollback. “Allow this command until the session ends” if you want.
  • history

    A chat keeps its server

    A chat works with the server it started on: no session — “offline” and “Connect”. History is encrypted with the document key.
  • folder

    Agent folders

    Attach a folder of knowledge to a server — AGENTS.md, skills, notes. The agent reads it on its own and writes only after your “yes”.
  • notifications

    Step away

    At “Full access” the agent works on without you: the Mac stays awake while it works, a card nobody answers in 2 minutes is set aside to wait for you, and a notification says when it’s done or needs an answer.
  • lock_open

    Claude Code and Codex without limits

    If you like — your skills, plugins and MCP, as in your own terminal. Servers still go through SSHKipper’s levels.

04databaseDatabases

A database client — right behind your bastions

Six engines, editable tables, a query editor and AI that turns words into SQL. Databases open through the same chain as the terminal — no ssh -L, no manual tunnels.

  • MySQL · MariaDB

    Editable tables, structure, DDL and a relationship map.

  • PostgreSQL

    Plus partitions, sequences and functions.

  • ClickHouse

    Partitions and compression per table.

  • Redis · Valkey

    Keys with TTL, memory by prefix and a console.

  • MongoDB

    Documents as a table or a tree, aggregations.

  • SQLite

    A file on a server (needs python3 there, not sqlite3) or on this Mac; read-only by default.
  • shield

    Production stays safe

    On a Production database every change opens a window with the full SQL and “Check with AI”, on a normal one only irreversible ones; read-only forbids changes altogether.
  • visibility

    The model doesn’t see your data

    The AI filter and “Compose” get only the columns and schema, never table rows.
  • auto_awesome

    The agent plays by the rules

    The AI agent reads the schema and runs queries by the database’s mode and its own level; password tables are always refused.
  • monitoring

    Processes, and a Stop that stops

    Who is connected and what runs: cancel a query or close a connection, with the exact statement in the question. Stop in the editor tells you whether the server took the cancel.
  • download

    A whole table

    Export to CSV, JSON or SQL INSERT, page by page — memory stays flat. A SELECT from one table with its key edits like the table itself.

06folder_openFiles and storage

Server, Mac and cloud files — in one window

SFTP goes through the same bastions; S3, WebDAV and cloud drives live in the same tree, and a storage put inside a server reaches the network through it. Drag and drop both ways and one transfer queue for everything.

  • terminal

    SFTP

    Any server in the document — same sign-in, no second 2FA.

  • S3-compatible

    AWS, Yandex Cloud, Selectel, Cloudflare R2, MinIO.

  • WebDAV · Nextcloud

    Nextcloud with browser sign-in.
  • cloud

    Cloud drives

    Google Drive, Yandex Disk and Dropbox. Sign in with SSHKipper (full version; on Google Drive and Dropbox, only SSHKipper’s own folder) or with your own Client ID (any version; the whole drive).
  • laptop_mac

    This Mac

    Two panes and drag and drop to and from Finder.
  • edit_square

    Your editor

    Open it in your editor, save — and it’s back on the server.
  • folder

    Permissions and Quick Look

    Permissions for many files at once; Space for a preview, as in Finder.
  • cloud

    Download and public links

    An S3 link for an hour, a day or a week; a Nextcloud or Yandex Disk public link — from the file’s menu.
  • swap_horiz

    Copies from a server to its bastion, and uploads to S3, WebDAV or Yandex Disk, go directly — your home connection stays free.
  • history

    A file’s versions, storage classes and Glacier restores; an s3:// address opens the right bucket; whatever you delete in Nextcloud comes back from its trash.
  • verified

Remote desktops — VNC, macOS Screen Sharing and RDP — go through the same chain; a Mac can also be shown through Sill for Mac, a free open-source app you install on it.

  • schedule

09shieldSecurity

Your keys stay yours

Passwords, keys and 2FA secrets live in one encrypted file on this Mac. The developer has no copy, no account and no telemetry: SSH goes to your servers, AI straight to the provider, and the document can lock itself. Only an automation you let run on a server with secrets puts them there, in 0600 files.

  • lock

    Encryption

    The whole document — Argon2id and XChaCha20-Poly1305.
  • fingerprint

    Touch ID

    A copy of the document key is guarded by this Mac’s Secure Enclave.
  • key

    Recovery key

    Forgot the password? The recovery key opens the document and lets you set a new one.
  • schedule

    Auto-lock

    On screen lock, sleep or idle — set per document.
  • keyboard

    Secure input

    Turn on Secure keyboard entry, and while the terminal takes input other apps can’t intercept keystrokes.
  • dns

    Host keys

    Its own known_hosts: a changed key gets a warning, not a silent sign-in.
  • visibility_off

    Masked secrets

    The document’s passwords and tokens of known formats are hidden in session logs and before anything goes to a model.
  • history

    Backups

    Encrypted copies of earlier versions: the last five, one per hour for a day, one per day for a week; not in Time Machine.
  • key

    No passwords in ps

    ssh gets passwords and codes through its own channel, databases through stdin: never in arguments or the environment.
  • description

    A shared document asks first

    Commands on this Mac, reverse tunnels and auto-start from a document someone sent you wait for your “yes”.
  • visibility_off

    No telemetry

    No analytics, no automatic crash reports: the app never tells the developer what you do or where.

10extensionExtensions and modules

Need a feature? Ask your agent to build it for you

SSHKipper grows with extensions — and anyone can write one. An extension adds what the app doesn’t have: a database engine, a storage, servers from a cloud’s API, tree items of your own with their own screen. A module is the simplest extension: one server service, often just sh scripts. The SDK is open and free (MIT): write it yourself or hand it to Claude Code or Codex.
