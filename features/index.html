01keyBastions and 2FA

A server behind two bastions — in one double-click

Normally that’s ssh -J, a password and a code from your phone at every hop. In SSHKipper, keys, passwords and 2FA secrets live in an encrypted document, and the app answers every hop itself. An ssh your own script starts gets them too — with ⌘⏎.

  • account_treeBastion through bastionA chain of any length opens with a double-click.
  • swap_horizSOCKS5 and HTTP proxiesWhen the first bastion is reachable only through a proxy.
  • verified_userTOTP from anythingA base32 secret, an otpauth:// link, a Google Authenticator export or a QR code.
  • descriptionImport ~/.ssh/configProxyJump turns into bastions, port forwards into tunnels.
  • Tailscale and BonjourMachines on your network appear in the tree on their own.
  • lanRoute profilesTailscale, an office address or another bastion — when the main way is down.
  • lanOne sign-in per serverTabs, splits, files, Docker and databases of a server share one connection.
  • keyHost keys under controlIts own known_hosts: if a host key changes, you get a warning, not a silent sign-in.
  • hubRoute mapHow this Mac reaches a server: bastions, proxies, keys and codes, drawn from the document.
  • touch_appOnly when you pressNothing is typed by itself: “Insert” or ⌘⏎ — and the code goes straight into the terminal, not via the clipboard.
  • terminalIn any terminalThis Mac’s terminal and SSH tabs alike: the server is found by user and address — any profile of a connection too.
  • key_verticalKey passphrases tooOnce, checked against the key file — then kept in the encrypted document; the key is recognised by its fingerprint.

Six engines, editable tables, a query editor and AI that turns words into SQL. Databases open through the same chain as the terminal — no ssh -L, no manual tunnels.

  • MySQL · MariaDBEditable tables, structure, DDL and a relationship map.
  • PostgreSQLPlus partitions, sequences and functions.
  • ClickHousePartitions and compression per table.
  • Redis · ValkeyKeys with TTL, memory by prefix and a console.
  • MongoDBDocuments as a table or a tree, aggregations.
  • SQLiteA file on a server or on this Mac.
  • shieldProduction stays safeOn a Production database every change opens a window with the full SQL and “Check with AI”, on a normal one only irreversible ones; read-only forbids changes altogether.

  • auto_awesomeThe agent plays by the rulesThe AI agent reads the schema and runs queries by the database’s mode and its own level; password tables are always refused.

09extensionExtensions and modules

Need a feature? Ask your agent to build it for you

SSHKipper grows with extensions — and anyone can write one. An extension adds what the app doesn’t have: a database engine, a storage, servers from a cloud’s API, tree items of your own with their own screen. A module is the simplest extension: one server service, often just sh scripts. The SDK is open and free: write it yourself or hand it to Claude Code or Codex.

10shieldSecurity

Your keys stay yours

Passwords, keys and 2FA secrets live in one encrypted file on this Mac. The developer has no copy, no account and no telemetry: SSH goes to your servers, AI straight to the provider, and the document can lock itself.

  • lockEncryptionThe whole document — Argon2id and XChaCha20-Poly1305.
  • fingerprintTouch IDA copy of the document key is guarded by this Mac’s Secure Enclave.
  • keyRecovery keyForgot the password? The recovery key opens the document and lets you set a new one.
  • scheduleAuto-lockOn screen lock, sleep or idle — set per document.
  • keyboardSecure inputWhile the terminal takes input, no other app can read your keystrokes.
  • dnsHost keysIts own known_hosts: a changed key gets a warning, not a silent sign-in.
  • visibility_offMasked secretsPasswords and tokens are hidden in session logs and before anything goes to a model.
  • historyBackupsEncrypted copies of earlier versions: the latest, hourly for a day, daily for a week.
  • keyNo passwords in psssh gets passwords and codes through its own channel, databases through stdin: never in arguments or the environment.
  • descriptionA shared document asks firstCommands on this Mac, reverse tunnels and auto-start from a document someone sent you wait for your “yes”.
  • visibility_offNo telemetryNo analytics, no crash reports: the app never tells the developer what you do or where.
