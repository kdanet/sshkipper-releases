# SSHKipper

Серверов много, а штурвал один. Нативный SSH-менеджер для macOS: бастионы и 2FA без ручного ввода, терминал с tmux,
службы серверов, базы данных, файлы, туннели, автоматизации и AI-агент — всё в одном зашифрованном документе.

- Сайт: https://sshkipper.com
- Скачать: [последний релиз](https://github.com/kdanet/sshkipper-releases/releases/latest/download/SSHKipper.dmg) (macOS 26+, Apple Silicon)

Этот репозиторий — сайт (GitHub Pages), лента обновлений Sparkle (`appcast.xml`) и релизы с DMG. Исходный код
приложения закрыт.

---

Many servers, one helm: a native SSH manager for macOS. This repository holds the website, the Sparkle update feed and the releases.
