# SSHKipper

Нативный SSH-менеджер для macOS: бастионы и 2FA без ручного ввода, все подключения в одном зашифрованном документе,
службы серверов, базы данных, автоматизации бэкапов и AI-агент в ваших сессиях.

- Сайт: https://kdanet.github.io/SSHkipper/
- Скачать: [последний релиз](https://github.com/kdanet/SSHkipper/releases/latest/download/SSHKipper.dmg) (macOS 26+, Apple Silicon)

Этот репозиторий — сайт (GitHub Pages), лента обновлений Sparkle (`appcast.xml`) и релизы с DMG. Исходный код
приложения закрыт.

A native SSH manager for macOS. This repository holds the website, the Sparkle update feed and the releases.
