# SSHKipper

Many servers, one helm: a native SSH manager for macOS. Bastions with keys, passwords and TOTP codes filled in, a terminal
with tmux, server services, databases, files, tunnels, remote desktops, automations and an AI agent — in one encrypted
document.

- Website: https://sshkipper.com
- Download: [latest release](https://github.com/kdanet/sshkipper-releases/releases/latest/download/SSHKipper.dmg) (macOS 26 or later, Apple Silicon)

This repository holds the website (GitHub Pages), the Sparkle update feed (`appcast.xml`) and the releases with the DMG.
The app's source code is closed. The pages are generated by `scripts/site/gen.py` in the app's repository; don't edit
the HTML by hand.
